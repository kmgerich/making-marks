I must come clean, I use AI in my job. I use it as a substitute for search engines. A search engine doesn't have any intelligence. It returns information based on the keywords that you give it, without knowing the context of what you are asking. If you type a paragraph of prose into the search engine to set the context, it will just return results from the search index ranked by the popularity of the source. There is no intelligence there. Google and other search engines have bolted an "AI Overview" in the search engine results, but let's leave that aside for now.

What if a search engine could infer "what do I mean?" when I type "I want a sandwich".
